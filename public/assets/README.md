# Vortex Fitness Club - Image Assets Directory

Place your custom images in this directory (`public/assets/`).
The application is pre-configured to automatically display them with high resolution and smooth aspect ratio handling.

### Required Images:
1. **`hero-banner.png` (or `.jpg`)**:
   - Location: Hero section background
   - Description: Muscular athlete deadlifting in atmospheric dark gym setting
   - Recommended resolution: `1360 x 600` or higher

2. **`bento-pulldown.png`**:
   - Location: Bento grid Column 1 (top)
   - Description: Athlete performing cable lat pulldown
   - Recommended resolution: `400 x 360` (portrait)

3. **`bento-dips.png`**:
